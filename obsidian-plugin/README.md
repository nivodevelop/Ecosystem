# Traffic Hub для Obsidian

Плагин для ведения приложений App Store прямо в хранилище Obsidian: канбан по этапам, локализации с бесплатным автопереводом и обрезкой по лимитам Apple, наборы скриншотов по локалям.

## Установка

1. Создайте папку `<ваше хранилище>/.obsidian/plugins/traffic-hub/`.
2. Положите в неё три файла: `main.js`, `manifest.json`, `styles.css`.
3. В Obsidian откройте Настройки → Сторонние плагины, отключите «Безопасный режим», нажмите «Обновить» и включите **Traffic Hub**.
4. Нажмите иконку канбана слева или выполните команду «Traffic Hub: Открыть канбан».

## Что умеет

- **Канбан.** Карточка показывает иконку, название, подзаголовок и 3 первых скрина основной локали. Перетаскивайте карточки между колонками и внутри колонки. Этапы (название, цвет, порядок) меняются кнопкой «Этапы»; при удалении этапа приложения переносятся в выбранный этап.
- **Страница приложения.** Вкладки «Основное» (Bundle ID, аккаунт App Store Connect, ссылка, иконка, заметки), «Локализации», «Скрины», «История» (переходы между этапами с датами).
- **Локализации.** Все 39 локалей App Store. При добавлении локалей тексты переводятся с выбранной исходной локали и обрезаются по лимитам Apple: название 30, подзаголовок 30, промо-текст 170, ключевые слова 100, описание и «Что нового» 4000. Обрезка идёт по границе слова или предложения, ключевые слова — целыми словами через запятую. Автоматические переводы помечены «авто», пока вы их не сохраните.
- **Скрины.** Загрузите картинки в библиотеку, соберите набор, расставьте порядок перетаскиванием, отметьте локали и нажмите «Применить».

## Перевод без платных API

По умолчанию используется бесплатный эндпоинт Google Translate. При большом числе запросов Google может временно ограничить доступ; такие локали плагин перечислит в уведомлении, их можно перевести позже кнопкой «Перевести заново».

Для стабильной работы можно поднять свой бесплатный [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate) (`docker run -p 5000:5000 libretranslate/libretranslate`) и указать адрес `http://localhost:5000` в настройках плагина. Языки, которых нет в LibreTranslate, автоматически переводятся через Google.

## Где хранятся данные

Всё лежит обычными файлами в папке `Traffic Hub` (меняется в настройках):

```
Traffic Hub/
  Этапы.md                      — список колонок канбана
  Sleep Sounds/
    Sleep Sounds.md             — карточка: этап, Bundle ID, история; ниже — ваши заметки
    Локализации/en-US.md, ru.md — тексты по локалям
    Скрины/*.png                — иконка и скриншоты
```

Файлы можно открывать и править вручную, плагин подхватит изменения.

## Синхронизация на несколько компьютеров (на будущее)

Так как данные — обычные файлы хранилища, подойдёт любой способ:

- **Obsidian Sync** — платная официальная синхронизация, самый простой вариант.
- **Syncthing** — бесплатно, синхронизирует папку хранилища между компьютерами напрямую.
- **Git** — плагин Obsidian Git и приватный репозиторий.

Плагин нужно установить на каждом компьютере (папка `.obsidian/plugins/traffic-hub` синхронизируется вместе с хранилищем, если синхронизация настроек включена).
