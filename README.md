# Traffic Hub

Внутренняя экосистема агентства: канбан приложений по этапам, локализации с автопереводом,
наборы скриншотов по локалям, роли сотрудников.

## Что умеет (MVP)

- **Роли.** Админ: всё, включая пользователей и удаление приложений. Менеджер: создаёт и
  редактирует приложения, локализации, скрины. Сотрудник: видит доску и двигает карточки.
- **Канбан.** По умолчанию этапы: Разработка, Первичная модерация, Реджект, Белая в сторе,
  Техническое обновление, Скрины, Работающая, Заблокированная. Админ на странице «Этапы»
  добавляет, переименовывает, перекрашивает, меняет порядок и удаляет колонки (приложения из
  удаляемой колонки переносятся в выбранную). Карточка: иконка, название,
  подзаголовок и первые 3 скрина основной локали. Перетаскивание между колонками и внутри
  колонки, история переходов (кто и когда).
- **Страница приложения:** основные данные (платформа, bundle ID, аккаунт, ссылка, заметки,
  иконка), смена этапа, история.
- **Локализации:** все 39 локалей App Store Connect, добавление всех разом, поля с лимитами символов Apple (название 30,
  подзаголовок 30, ключи 100 и т. д.), подсветка превышения. Добавление локалей с
  автопереводом из любой существующей и повторный перевод выбранных локалей. Переведённые
  автоматически помечаются «авто», пока их не проверит и не сохранит человек.
- **Скрины:** загрузка пачкой, сборка набора кликами, порядок перетаскиванием,
  применение набора к отмеченным локалям (до 10 в локали).
- **Вкладка «Позиции»** (только админ) пока заглушка — отслеживание ключей следующим этапом.

## Стек

Next.js 15 (App Router, server actions), TypeScript, Tailwind (тёмная тема), PostgreSQL + Prisma,
dnd-kit. Файлы хранятся на диске (`STORAGE_DIR`).

## Автоперевод (бесплатно, без платных API)

- **Без настройки** используется бесплатный веб-эндпоинт Google Translate. Он работает без ключа,
  но неофициальный: при частых запросах Google может временно ограничить сервер.
- **Рекомендуется для команды:** свой LibreTranslate (open source) в docker-compose:
  `docker compose --profile translate up -d` и `LIBRETRANSLATE_URL="http://localhost:5000"` в `.env`.
  Без лимитов и внешних сервисов. Языки, которых нет в LibreTranslate (например, хорватский),
  автоматически переводятся через бесплатный Google.
- Перевод автоматически обрезается по лимитам App Store: название и подзаголовок до 30 символов
  без разрыва слов, ключевые слова до 100 символов целыми словами, длинные тексты по концу
  предложения. Автопереведённые локали помечаются «авто», пока их не проверит человек.

## Запуск локально

Нужны Node.js 20+ и PostgreSQL (можно через Docker).

```bash
docker compose up -d            # PostgreSQL на localhost:5432
cp .env.example .env            # и поменяйте AUTH_SECRET
npm install
npx prisma migrate deploy       # создать таблицы и этапы по умолчанию
npm run db:seed                 # первый админ: admin@example.com / admin12345
npm run dev                     # http://localhost:3000
```

Свой логин для первого админа: `ADMIN_EMAIL=... ADMIN_PASSWORD=... npm run db:seed`.

### Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | строка подключения PostgreSQL |
| `AUTH_SECRET` | секрет для подписи сессий, длинная случайная строка |
| `STORAGE_DIR` | папка для иконок и скринов (по умолчанию `./storage`) |
| `LIBRETRANSLATE_URL` | адрес своего LibreTranslate; без него перевод идёт через бесплатный Google |
| `LIBRETRANSLATE_API_KEY` | ключ, только если он включён на вашем LibreTranslate |

## Размещение в сети

В репозитории есть `Dockerfile`. При старте контейнер сам применяет миграции и создаёт
первого админа из `ADMIN_EMAIL` / `ADMIN_PASSWORD`, если его ещё нет. Сайт должен работать
по HTTPS: cookie сессии в продакшене передаётся только по защищённому соединению.

### Railway

1. New Project → Deploy from GitHub repo → выбрать репозиторий (Dockerfile подхватится сам).
2. В проекте: New → Database → PostgreSQL.
3. В сервисе приложения, Variables: `DATABASE_URL=${{Postgres.DATABASE_URL}}`,
   `AUTH_SECRET` (длинная случайная строка), `ADMIN_EMAIL`, `ADMIN_PASSWORD`.
4. Settings → Volumes: добавить том с путём `/data` (там иконки и скрины).
5. Settings → Networking → Generate Domain. Это и есть ссылка.

### Render

В репозитории есть `render.yaml`. Render → New → Blueprint → выбрать репозиторий, указать
`ADMIN_EMAIL` и `ADMIN_PASSWORD` (почта и пароль первого админа), `LIBRETRANSLATE_URL` можно
оставить пустым. Render сам создаст базу, диск и выдаст адрес вида `https://ecosystem-xxxx.onrender.com`.

### Свой сервер

```bash
echo 'AUTH_SECRET=длинная-случайная-строка' > .env
docker compose --profile app up -d --build      # приложение на порту 3000
```

Перед ним нужен reverse proxy с HTTPS (Caddy или nginx). Бэкапить том `files` и базу.

## Структура

- `prisma/schema.prisma` — модель данных
- `src/actions/` — серверные действия (приложения, этапы, локализации, скрины, пользователи)
- `src/components/` — доска, вкладки локализаций и скринов
- `src/lib/` — авторизация, права, локали и лимиты, перевод, хранилище
